Сохранение игры

Игра хранит на устройстве выбранное игровое имя, настройки, монеты, открытые машины, улучшения, задания и полученные награды. Регистрация и облачный аккаунт не требуются. Разработчик не получает эти сохранения на собственный сервер. Удалить их можно через очистку данных приложения в настройках Android; действие удаляет игровой прогресс.

Локальные бои

Во время игры по Wi-Fi или Bluetooth устройствам участников передаются игровое имя, выбранный танк, характеристики и состояние боя. Телефон сервера управляет боем. Wi-Fi использует локальные сетевые адреса, Bluetooth — сведения о сопряжённых устройствах. Разрешение Bluetooth требуется для подключения к выбранному устройству. Не указывайте в игровом имени личные или конфиденциальные сведения.

Реклама и аналитика

Версия 0.9.0 не содержит рекламы и рекламного SDK. Начиная с версии 0.10.0 игра использует Yandex Mobile Ads SDK (8.4.0 в версии 0.10, 8.6.0 начиная с версии 0.11) для добровольного просмотра рекламы за награду: золотой вариант выбранной машины навсегда или самонаведение до первой смерти. Для просмотра нужен интернет; одиночные и локальные бои доступны без просмотра рекламы. Встроенных покупок за реальные деньги нет.

При инициализации SDK и запросе рекламы устройство связывается с рекламной сетью Яндекса. SDK может обрабатывать рекламный и другие идентификаторы устройства в зависимости от разрешений Android; при сетевом обращении серверу доступен IP-адрес. Рекламная сеть получает сведения, необходимые для загрузки объявления и учёта показа и вознаграждения. Игровое имя, монеты и сохранения разработчик в рекламную сеть не передаёт. При подготовке показа игра передаёт значение userConsent=false. В версии 0.10 SDK может автоматически инициализироваться при запуске приложения. Начиная с версии 0.11 автоматическая инициализация отключена: SDK запускается после нажатия кнопки рекламы, с предварительно установленным userConsent=false. Разрешение на точное местоположение для рекламы не запрашивается, согласие на передачу геолокации не включается.

Обработка данных рекламной сетью описана в Политике конфиденциальности Яндекса. Сведения об идентификаторах SDK: документация Яндекса. Настройки рекламного идентификатора доступны в настройках Android. Можно не нажимать кнопки просмотра рекламы и продолжать играть. Квитанция о выданной награде хранится локально для защиты от повторного начисления.
